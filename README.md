# 📘 دليلك — موقع عربي جاهز للتقديم على Google AdSense

موقع محتوى عربي متكامل (نصائح منزلية، وصفات، معلومات عامة، تكنولوجيا) مبني ليكون مقبولًا في **Google AdSense** من أول تقديم، مع كل المتطلبات الأساسية:

- ✅ **16 مقالًا أصليًا كاملًا** (مكتوبون خصيصًا، كل مقال 400-600 كلمة)
- ✅ صفحات أساسية: **من نحن، اتصل بنا، سياسة الخصوصية، شروط الاستخدام**
- ✅ **sitemap.xml + robots.txt** لسهولة فحص جوجل
- ✅ تحسين SEO: عناوين، أوصاف، JSON-LD (مخطط المقال والموقع)
- ✅ تصميم سريع ومتوافق مع الجوال (بدون أي مكتبات خارجية — سرعة عالية)
- ✅ لا يحتاج قاعدة بيانات أو خادم — ملفات ثابتة تعمل على أي استضافة مجانية

---

## 🚀 خطوات النشر (اختيار واحد)

### الخيار 1: GitHub Pages (مجاني)
1. أنشئ مستودعًا جديدًا على GitHub (اسم مثل `dalilak`).
2. ارفع محتويات مجلد `dalilak-site` إلى المستودع.
3. اذهب إلى **Settings ← Pages** واختر المصدر `main branch` — سيتم النشر فورًا.
4. ستحصل على رابط مثل: `https://username.github.io/dalilak`

### الخيار 2: Netlify أو Cloudflare Pages (مجاني)
- ارفع الملفات مباشرة من المتصفح (اسحب وأفلت مجلد `dalilak-site`)، أو اربط مستودع GitHub.

### الخيار 3: استضافة مدفوعة
- أي استضافة تدعم ملفات HTML ثابتة، ويفضل ربط **دومين خاص** (الأفضل لقبول أدسنس).

---

## 📌 بعد النشر — قبل التقديم على أدسنس

### 1. غيّر اسم النطاق في الملفات
افتح `builder/site_data.py` وعدّل:
```python
"url": "https://www.dalilak.com",   # ← ضع دومينك الحقيقي هنا
"email": "contact@dalilak.com",     # ← بريدك الحقيقي
```
ثم شغّل مجددًا:
```bash
cd builder && python3 build_site.py
```
(يحدّث الروابط التلقائية في sitemap والـ JSON-LD)

### 2. أضف المزيد من المقالات (مهم جدًا)
كلما زاد المحتوى الأصلي زادت فرصة القبول:
- افتح `builder/articles_data_1.py` أو `articles_data_2.py`
- انسخ أي مقال (بين `{...},`) وعدّل بياناته (slug، title، body...)
- شغّل `python3 build_site.py` مرة أخرى — كل شيء يُبنى تلقائيًا

### 3. تأكد من الصفحات
- جرّب كل الروابط، وتأكد أن كل صفحة تعمل على الجوال.
- أضف 1-2 مقال جديد أسبوعيًا (الاستمرارية = ثقة جوجل).

### 4. قدّم طلب أدسنس
1. اذهب إلى [adsense.google.com](https://adsense.google.com) وسجّل.
2. أدخل رابط موقعك (يجب أن يكون الموقع **منشورًا وظاهرًا** وليس تحت الإنشاء).
3. انتظر المراجعة (من يومين إلى أسبوعين عادة).

---

## 💡 نصائح لزيادة فرصة القبول
- **الدومين الخاص** يرفع الفرصة كثيرًا (دومين بسيط مثل `.com` بـ 5-10$ سنويًا من Namecheap أو GoDaddy).
- انشر **5-10 مقالات إضافية** قبل التقديم (وصفات ونصائح منزلية من أكثر المجالات قبولًا).
- لا تنسخ محتوى من أي موقع — جوجل يكشف النسخ فورًا.
- تأكد أن صفحات «سياسة الخصوصية» و«اتصل بنا» تظهر في الفوتر.

## 📁 بنية الملفات
```
dalakil-site/           ← الموقع الجاهز للنشر
├── index.html          ← الرئيسية
├── category/           ← صفحات الأقسام (4)
├── posts/              ← المقالات (16)
├── about.html          ← من نحن
├── contact.html        ← اتصل بنا
├── privacy-policy.html ← سياسة الخصوصية
├── terms.html          ← شروط الاستخدام
├── sitemap.xml
├── robots.txt
└── 404.html

builder/                ← كود التوليد (لإضافة مقالات جديدة)
├── build_site.py       ← السكربت الرئيسي
├── site_data.py        ← إعدادات الموقع
└── articles_data_1/2.py ← محتوى المقالات
```
