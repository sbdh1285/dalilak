# هوية «بوصلة المعرفة» — دليلك 2.0

توثيق الهوية البصرية الجديدة لموقع دليلك (سبتمبر 2026). أي تعديل مستقبلي على الهوية يجب أن يبدأ من هذا الملف ومن `site-config.json`.

## الفكرة

«دليلك» تعني البوصلة التي تدلّك. الشعار إبرة بوصلة رُباعية داخل مربع نيلي بزوايا دائرية، تشير نحو بداية القراءة العربية (أعلى اليسار). نصفها الأمامي عنبري ونصفها الخلفي نيلي فاتح، وفي مركزها نقطة بيضاء.

## الخطوط

- **Alexandria** للعناوين والشعار: أوزان 500/600/700/800 — ملفات `fonts/alexandria-{arabic,latin}-{500..800}.woff2` (13KB لكل ملف).
- **Tajawal** للنصوص: أوزان 400/700/800.
- كلاهما مستضاف محليًا مع `unicode-range` للفصل بين العربي واللاتيني (الأرقام اللاتينية تعمل).
- لا تستخدم `letter-spacing` مع النصوص العربية أبدًا (يقطع اتصال الحروف).

## اللمسات المتكررة (Motifs)

- **المعيّن**: مربع صغير مائل 45° (إبرة البوصلة) يظهر قبل العناوين الفرعية وفي القوائم وفواصل السطر التعريفية.
- **الأشكال الحبّية**: الأزرار وشرائح التصنيف وحقل البحث `border-radius:999px`.
- **الظلال النيلية**: `rgba(23,30,80,…)` بثلاث طبقات بدل الرمادي التقليدي.
- **الشريط العلوي**: تدرج نيلي مع رابط أبيض يتحول عنبريًا عند التحويم.

## مصادر الحقيقة (عدّل هنا فقط)

1. `site-config.json` → قسم `theme` (تزامنه أداة `redesign_magazine.py` تلقائيًا مع `css/style.css`).
2. `css/style.css` و`css/editorial.css` → نظام التصميم كاملًا.
3. `tools/redesign_magazine.py` → `LOGO_ICON` (الشعار)، `update_favicon()`، إصدارات CSS، وألوان `theme-color`.
4. `manifest.json` → ألوان التطبيق والأيقونات.
5. أصول الشعار: `favicon.svg` و`images/icon-{192,512,maskable-512}.png` و`images/og-default.png`.

بعد أي تعديل:

```bash
python3 tools/redesign_magazine.py
python3 tools/audit_site.py
```

## ملاحظات تقنية

- إصدار CSS الحالي `?v=21` و`js/main.js?v=2` — ارفع الرقم عند أي تعديل لكسر الكاش.
- بطاقة المقال الرئيسي في الصفحة الرئيسية تستخدم نصًا فوق الصورة مع تدرج نيلي غامق أسفلها لضمان التباين.
- الصفحة الرئيسية التحريرية (`ed-*`) محمية في `redesign_home()`: الأداة لا تستبدلها بل تكتفي بتحديث الهيدر والفوتر.
- كل أزواج الألوان الرئيسية اجتازت فحص WCAG 2.1 AA (نسبة تباين ≥ 4.5:1).
