# الفهرسة الفورية عبر IndexNow

يُبلغ هذا السير العمل محركات البحث المشاركة في بروتوكول [IndexNow](https://www.indexnow.org/) —
**Bing وYandex وSeznam** (عبر النقطة الموحّدة `api.indexnow.org`) — بأي صفحة تُنشَر أو
تُحدَّث، خلال ثوانٍ من الدمج في `main`، دون انتظار زحف الروبوتات الدوري.

## المكوّنات

| المكوّن | المسار | الدور |
| --- | --- | --- |
| سير العمل | `.github/workflows/indexnow.yml` | يعمل تلقائيًا مع كل دفع إلى `main` |
| السكربت | `tools/indexnow_ping.py` | يجمع الروابط ويرسلها وفق البروتوكول |
| ملف المفتاح | `802a76e0d0d3475387f699059cb74eef.txt` | إثبات ملكية الموقع، منشور على: <https://sbdh1285.github.io/dalilak/802a76e0d0d3475387f699059cb74eef.txt> |

رابط الموقع يُقرأ من `site-config.json` (`baseUrl`)، وعند ربط دومين مستقبليًا عبر
`tools/configure_domain.py` يتبنّى السكربت الدومين الجديد تلقائيًا دون أي تعديل.

## متى يعمل؟

| الحدث | ما الذي يُرسَل؟ |
| --- | --- |
| دفع/دمج إلى `main` | الصفحات HTML التي تغيّرت في الدفع (ويشمل أي مقال جديد) — وإن لم يتغيّر شيء، يُرسَل أحدث 10 مقالات من `feed.xml` |
| تشغيل يدوي (تبويب Actions ← IndexNow ← Run workflow) | الرابط المُدخل في حقل `url`، أو أحدث المقالات إن تُرك فارغًا |
| جدولة أسبوعية (الأحد 03:30 UTC) | إشعار كامل بكل روابط `sitemap.xml` كضمانة اكتشاف |

## التشغيل اليدوي من سطر الأوامر

```bash
python3 tools/indexnow_ping.py --git-before <sha>          # تغييرات دفع محدد
python3 tools/indexnow_ping.py --url https://.../post.html # رابط واحد
python3 tools/indexnow_ping.py --sitemap                   # إشعار كامل
python3 tools/indexnow_ping.py --feed-top 10 --dry-run     # تجربة دون إرسال
```

## الاستجابات المتوقعة

- `200 OK` / `202 Accepted`: نجاح — الروابط دخلت طابور المحركات.
- `429 Too Many Requests`: تجاوز وتيرة الطلبات — يُعامَل كتحذير ولا يُفشل السير عمل.
- `400` / `403` / `422`: خطأ إعداد (مفتاح أو نطاق) — يُفشل السير عمل ليكون ملحوظًا.

## ملاحظات

- لا تُرسَل صفحات `noindex` (`404.html` و`search.html` و`thanks.html`) ولا ملف توثيق Google.
- الحد الأقصى للبروتوكول 10,000 رابط للطلب الواحد؛ السكربت يقتطع عند الحد تلقائيًا.
- يحق للمحركات ترتيب أولوياتها بعد الاستلام؛ IndexNow يضمن الإبلاغ الفوري لا الفهرسة اللحظية المضمونة، وهو أسرع مسار متاح اليوم.
