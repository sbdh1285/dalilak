# حزمة تطوير المحتوى قبل الدومين

**التاريخ:** 17 أغسطس 2026

## المنجز

- مراجعة المقالات الداعمة العشرين وإضافة ملاحظات دقة وقوائم عملية.
- إعادة كتابة مقالي جسم الإنسان ومكافحة الحشرات لإزالة الادعاءات المبالغ فيها.
- توثيق 31 مقالًا بمصادر رسمية أو مرجعية.
- إنشاء 34 غلافًا تحريريًا مستقلًا بلا نصوص أو تدرجات.
- نشر أربعة مقالات عملية جديدة: سلامة مواد التنظيف، استرداد الحسابات، فحص الهاتف المستعمل، وبهارات الأرز الخليجي.
- إنشاء أربعة أدلة موضوعية تربط المقالات في عناقيد واضحة.
- تعطيل نموذج التواصل مؤقتًا مع إعداد أداة ربط الدومين والبريد.
- التأكد من عدم إضافة كود AdSense، والإبقاء على ads.txt كقالب معلّق فقط.

## المقالات الجديدة

- `cleaning-products-never-mix`: مواد تنظيف لا تخلطها معًا: جدول سلامة منزلي
- `account-recovery-plan`: خطة استرداد الحسابات قبل الاختراق: ورقة عمل عملية
- `used-smartphone-checklist`: شراء هاتف مستعمل: قائمة فحص قبل الدفع
- `gulf-rice-spices-guide`: دليل بهارات الأرز الخليجي: الكبسة والمندي والمجبوس

## صفحات العناقيد

- `guide-safe-cleaning.html`: دليل التنظيف الآمن
- `guide-account-security.html`: دليل حماية الحسابات
- `guide-gulf-recipes.html`: دليل الوصفات الخليجية
- `guide-smartphone.html`: دليل اختيار واستخدام الهاتف

## أداة الدومين

بعد شراء الدومين وإنشاء البريد:

```bash
python3 tools/configure_domain.py --domain example.com --email contact@example.com --enable-contact
```

لا تستخدم `--enable-contact` قبل إنشاء البريد والتأكد من استقبال الرسائل.
